# 开发路线

| 优先级 | 内容 | 状态 |
| --- | --- | --- |
| P0 | Phase 1-4：认证、活动审核、报名、动态二维码签到 | 已完成 |

| P7 | AI 文案助手 | 代码已完成，默认关闭，密钥配置延后 |

当前先完成二维码在手机网络中的端到端验证。公网或校园网正式部署需要服务器、域名、HTTPS 证书及相应网络权限，这部分不由应用代码单独决定。
