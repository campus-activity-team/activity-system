# 开发路线

| 优先级 | 内容 | 状态 |
| --- | --- | --- |
| P0 | Phase 1-4：认证、活动审核、报名、动态二维码签到 | 已完成 |
| P1 | 二维码联网：运行时地址配置、局域网访问、HTTPS 部署 | 局域网已完成；真实域名与 HTTPS 待部署 |
| P2 | 位置签到与防作弊：定位范围、动态二维码、异常签到记录 | 功能已完成；HTTPS 手机实测待完成 |
| P3 | 身份与权限治理：发起者申请审批、管理员授权、角色操作审计 | 已完成 |
| P4 | 活动反馈、评分与统计看板 | 已完成 |
| P5 | 名单导出、活动手动开启/结束、手动补签/撤销、通知提醒、操作日志查询 | 已完成 |
| P6 | 账号安全：修改密码、管理员重置、资料维护、令牌失效 | 待开发 |
| P7 | 工程与隐私：自动迁移、备份恢复、CI、限流、脱敏和数据保留策略 | 待开发 |
| P8 | 微信小程序适配 | API 稳定后实施 |
| P9 | AI 文案助手 | 代码已完成，默认关闭，密钥配置延后 |

下一阶段进入账号安全：修改密码、管理员重置、资料维护和令牌失效。公网或校园网正式部署需要服务器、域名、HTTPS 证书及相应网络权限，这部分不由应用代码单独决定。
